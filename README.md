# Chocolate Sales Data Analysis & Visualization

## Project Overview

This project focuses on analyzing and visualizing chocolate sales data using Python. The analysis explores sales performance across products, countries, and salespersons to identify important business insights and opportunities.

The project includes data cleaning, data analysis, visualization, and business recommendations.

## Project Objectives

* Clean and prepare sales data for analysis
* Analyze overall sales and revenue
* Identify high-performing and low-performing products
* Analyze sales performance by country
* Analyze salesperson performance
* Identify important sales trends and patterns
* Generate business insights and recommendations

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook
* Microsoft Excel

## Dataset

The project uses chocolate sales data containing information used for product, country, and salesperson analysis.

## Analysis Performed

### Data Cleaning

* Checked data types
* Converted date values into datetime format
* Checked missing values
* Removed duplicate records
* Combined sales data for analysis

### Sales Analysis

The analysis includes:

* Total revenue
* Number of orders
* Average order value
* Product sales performance
* Country-wise sales performance
* Salesperson performance

### Product Analysis

The project identifies:

* Best-selling products
* Products generating the highest revenue
* Low-performing products
* Average sales by product

### Country Analysis

The project compares sales performance across:

* Australia
* Canada
* India
* New Zealand
* UK
* USA

### Salesperson Analysis

The project analyzes salesperson performance and identifies high-performing and low-performing salespersons.

## Key Result

The reported total sales revenue is **₹61,83,625**.

## Business Insights

The analysis provides recommendations related to:

* Increasing marketing in high-performing regions
* Improving low-selling products
* Focusing on top-selling products
* Recognizing high-performing salespersons
* Expanding into high-growth markets
